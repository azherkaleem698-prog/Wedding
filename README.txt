HOW TO ADD OR REPLACE WEDDING PHOTOS:
======================================

1. Place your photo files into this directory (assets/images/).
2. You can use standard images (JPEG, PNG, WEBP, SVG).
3. To replace existing gallery placeholders:
   - Rename your photos to: gallery-1.jpg, gallery-2.jpg, gallery-3.jpg, gallery-4.jpg, gallery-5.jpg, gallery-6.jpg
   - Update the file extension in index.html (e.g. from .svg to .jpg) if needed.
4. The wedding website's gallery automatically includes smooth hover zoom effects and an interactive full-screen lightbox image viewer.
